Text Tagger

Text Tagger is a simple tool for annotating text collaboratively in Google Docs.

Add hashtags in comments on highlighted text in Google Docs. Text Tagger collects those annotations across a Google Drive folder and writes them to a Sheet for analysis.

Output includes tag summaries and simple document–tag and tag–tag edgelists.

Text Tagger is designed for qualitative data analysis and other collaborative text annotation projects.
