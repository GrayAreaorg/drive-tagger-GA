Text Tagger Privacy Policy

Updated: September 19, 2026

Text Tagger is a tool for collaboratively annotating text in Google Docs. It reads tagged comments from Google Docs in designated Drive folders and writes the resulting annotations and summaries to a designated Google Sheet.

Data accessed and used

Text Tagger uses Google OAuth to access files in Google Drive, including Google Docs and Google Sheets. It reads document titles, highlighted text, comments and replies, commenter display names, and document identifiers from a folder registered with the tool. It writes extracted tags, associated text, summary and synchronization data to a Google Sheet designated by the user.

Text Tagger uses Google permissions only to operate on folders and spreadsheets that users explicitly designate.

Text Tagger does not use Google user data for advertising, sell it, or use it to train AI or machine-learning models.

Storage and sharing

Text Tagger processes data on the server running the application. Its output is stored in the Google Sheets designated by users. Data written to Google Sheets remains subject to the sharing settings of users’ designated Sheets. The application processes document and comment contents only as needed to produce the designated Google Sheet output, and does not store a separate copy on the application server.

OAuth credentials and authorization tokens are stored on the server and are accessible only to the application administrator.

Text Tagger does not transfer or disclose Google user data to third parties. Users may choose to share data in designated Sheets using Google’s own permissions.

Deactivating projects and deleting data

A registered project can be deactivated or removed from Text Tagger. Output already written to user-controlled Google Sheets will remain in Sheets and can be deleted by users.

Contact

Questions about Text Tagger or its handling of data may be sent to:
privacy@texttagger.com

Text Tagger’s use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.
